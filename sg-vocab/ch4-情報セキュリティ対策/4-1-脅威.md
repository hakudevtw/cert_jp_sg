4-1 先講**威脅也分三類**——人的・技術的・物理的。

> **整章是一個鏡像：4-1 列出三種威脅，4-2〜4-4 各自回答一種。**

## ② 脅威の3分類

**分類依據是威脅「透過什麼手段」發生。**

| 分類 | 手段 | 例 |
|---|---|---|
| **人的脅威** | **人的行為本身** | 盗み見、不正利用、ソーシャルエンジニアリング、誤操作、紛失 |
| **技術的脅威** | **使用技術** | 不正アクセス、盗聴、なりすまし、改ざん、エラー、クラッキング |
| **物理的脅威** | **直接破壞情報資産** | 破壊、窃盗、不正侵入、事故、故障、自然災害 |

### 各類的例子說明

**人的脅威**

| 用語 | 內容 |
|---|---|
| 盗み見 | 偷偷看（螢幕、肩後） |
| 不正利用 | 不正當地使用 |
| **ソーシャルエンジニアリング** | **不靠技術**，利用人心理上的破綻或行為疏失取得機密。例：電話巧妙套話、偷看肩後的輸入、翻垃圾桶（→ 1-10） |
| 誤操作 | 操作失誤 |
| 紛失 | 把情報資産本身弄丟 |

**技術的脅威**

| 用語 | 內容 |
|---|---|
| 不正アクセス | 沒有存取權限的入侵者進行存取 |
| 盗聴 | 竊取內容。不只是聽通話，**看資料、複製、保存也算** |
| なりすまし | 冒充本人登入 |
| 改ざん | 把網頁或文件改寫成別的內容（改成原本不該有的內容） |
| エラー | 程式的 bug 造成系統停止 |
| クラッキング | 有惡意目的、具高技術力的人破壞系統 |

**物理的脅威**

| 用語 | 內容 |
|---|---|
| 破壊 | 入侵者故意破壞 |
| 窃盗 | 入侵者帶走情報資産 |
| 不正侵入 | 進入只有管理者能進的伺服器機房 |
| 事故 | 不小心掉落造成損壞 |
| 故障 | 經年劣化而故障 |
| 自然災害 | 地震、洪水、火災造成損壞 |

### 三個補充

- **人的脅威中最不能輕忽的是「內部不正」**——組織內部發生的威脅大多來自人。
- **物理的脅威損害的是「可用性」**——系統或資料壞了，就用不了。它常被認為跟資安無關，**所以更要注意**。
- **ソーシャルエンジニアリング 屬於「人的」**，因為它鑽的是人的漏洞，不是技術的漏洞。

## ③ 故意與偶發：每一類都有

| | **故意（意図的）** | **偶發（偶発的）** |
|---|---|---|
| **人的** | 盗み見、不正利用 | **誤操作、紛失** |
| **技術的** | マルウェア、不正アクセス | **エラー** |
| **物理的** | 破壊、窃盗 | **事故、故障、自然災害** |

**呼應 3-1**：資安管理必須同時處理「故意」與「偶發」，而實際事故中偶發的比例很高。

## ④ ⚠️ 考點：三組相似詞，分屬不同類

| 人的 | | 其他類 |
|---|---|---|
| **盗み見**（偷看螢幕、肩後） | ↔ | **盗聴**（竊聽通信）→ **技術的** |
| **紛失**（自己弄丟） | ↔ | **窃盗**（被偷走）→ **物理的** |
| | | **不正侵入**（人進入建築物）→ **物理的** ↔ **不正アクセス**（經網路入侵）→ **技術的** |

### 判斷法

> **先問「靠什麼發生的」——人的行為？技術？物理上的力量？**
> **不要看結果。**

例：員工誤操作導致資料被破壞——結果是「破壞」，**但手段是人的操作失誤 → 人的脅威**，不是物理的。

### 典型題型：「原因が物理的脅威に分類されるものはどれか」

| 情境 | 分類 | 理由 |
|---|---|---|
| 大雨使伺服器室進水，機器停止 | **物理的** ✓ | 自然災害**直接**破壞情報資産 |
| 外部送入大量資料，公開伺服器停止 | 技術的 | クラッキング |
| 攻擊者經網路侵入內部伺服器，破壞檔案 | 技術的 | 不正アクセス——**雖然結果是檔案被破壞，手段是網路** |
| 員工誤操作電腦，資料被破壞 | 人的 | 誤操作 |

> **第三、四個選項是陷阱：結果都是「破壞」，但手段不是物理力量。**

## 前因後果

**4-1 的價值不在於記住清單，而在於建立一個「分類的習慣」。**

Ch1 讀了幾十種攻擊，但幾乎全是**技術的脅威**。4-1 把視野拉開：

> **資安威脅中，技術的只是三分之一。**
> **電腦被搬走、機房淹水、員工把 USB 忘在電車上——這些不需要任何技術，卻同樣會讓資訊外洩或無法使用。**

**而分類的目的，是為了找對「對策的種類」：**

| 威脅 | 對應的對策 | 在哪 |
|---|---|---|
| 人的脅威 | **人的対策**（教育、規則、嚇阻） | **4-2** |
| 技術的脅威 | **技術的対策**（產品、加密） | **4-3、Ch5** |
| 物理的脅威 | **物理的対策**（入退室管理、備援） | **4-4** |

**用錯類別的對策是無效的**——防火牆擋不住員工把資料印出來帶走，資安教育擋不住地震。
**這也是為什麼「判斷手段而非結果」這麼重要：分類分錯，對策就會選錯。**
