## ① 全體地圖

```
知的財産権
├─ ① 著作権 ─────────────── 著作権法　　（文化面的創作，不用申請）
├─ ② 産業財産権　　　　　　　　　　　　　（產業面，要向特許庁申請）
│　　├─ 特許権 ───────── 特許法
│　　├─ 実用新案権 ─────── 実用新案法

│　　└─ 商標権 ───────── 商標法
└─ ③ その他（営業秘密など）── 不正競争防止法（不申請，靠藏好）
```

| 權利 | 保護什麼 | 例子 |
|---|---|---|
| 著作権 | 創作的**表現** | 小說、音樂、照片、**程式碼** |
| 特許権 | 高度的**發明** | QR Code、藍光 LED |
| 実用新案権 | 形狀、構造上的**小改良** | 鉛筆尾端加橡皮擦、杯子內側刻度 |
| 意匠権 | **外觀設計** | 椅子造型、飲料瓶造型 |
| 商標権 | **名稱、標誌** | 品牌名、logo |
| 営業秘密 | 企業內部 **know-how** | 飲料配方、客戶名單 |

**實用新案 vs 意匠：實用新案＝「更好用」（功能、構造）；意匠＝「更好看」（外觀）。**

**一個 App 拆開來看：** 程式碼＝著作権；核心演算法＝特許権（若申請）；App 名稱與 icon＝商標権；推薦參數、客戶名單＝営業秘密。

## ② 著作権法

SG 主要從**程式**的角度考：公司每天寫程式、買軟體、外包開發，「這段程式碼屬於誰、能不能改、能不能複製」都是著作權問題。

### 著作権分兩半

| | 著作者人格権 | 著作財産権 |
|---|---|---|
| 保護 | 作者的名譽、心情（「這是我的作品」） | 經濟利益（「這能賺錢」） |
| 轉讓 | ❌ **不能轉讓**，跟著人走 | ✅ 可以轉讓 |
| 內容 | 公表権・氏名表示権・同一性保持権 | 複製権・上演権・公衆送信権・口述権 等 |

| 權利 | 例子 |
|---|---|
| 公表権 | 寫到一半的小說，出版社不能擅自先發表 |
| 氏名表示権 | 作者可以要求用筆名，或一定要署名 |
| 同一性保持権 | 別人把你的照片亂修後當成你的作品發表 |
| 複製権 | 把買來的軟體拷貝給朋友 |
| 公衆送信権 | 把別人的漫畫上傳到網站 |
| 上演権／口述権 | 公開演出別人的劇本／公開朗讀別人的小說 |

**著作權賣掉後，原作者仍可依同一性保持権反對擅自修改**（人格権賣不掉）。因此實務上買方會在合約加上「作者不行使人格權」的約定。若是職務著作，作者本身就是公司，人格権也屬於公司。

### 程式的哪些部分受保護（最常考）

| 受保護 ✅ | 不受保護 ❌ |
|---|---|
| 程式（原始碼、執行檔） | プログラム言語（Python、C 本身）＝**工具** |
| データベース（選擇、結構有創意者） | 規約（API 呼叫格式、通訊協定）＝**約定** |
| | 解法＝アルゴリズム＝**想法** |

> **原理：著作權保護「表現」，不保護「想法」和「工具」。** 判斷標準不是「有沒有花心思」，而是「是不是具體寫出來的東西」。
> 同一個「加密」：加密演算法（想法）→ 要保護得走特許；用 C 寫出來的加密程式（表現）→ 著作權。
> 規約不能受保護的理由：規約本來就是要讓別人照著用的，有著作權的話誰照著寫都侵權，規約就失去意義。

### 其他考點

| 考點 | 內容 |
|---|---|
| **不用申請** | 創作完成那一刻自動發生（無方式主義），寫完存檔就有 |
| **保護期間** | **作者死後 70 年** |
| **職務著作** | 員工在職務上做的作品，原則上**屬於公司（法人）** |
| **為了提速而改買來的程式** | **合法**：合法持有者為了在自己電腦上使用，可做必要修改；但改完拿去賣、分給別人就不行 |

## ③ 産業財産権・営業秘密・不正競争防止法

### 産業財産権：申請才有，代價是公開

向特許庁申請、審查、登記後才發生，**內容必須公開**。

| 權利 | 保護期間 |
|---|---|
| 特許権 | **申請日起 20 年**（主要考這個） |
| 実用新案権 | 申請日起 10 年 |
| 意匠権 | 申請日起 25 年 |
| 商標権 | 登記起 10 年，**可無限更新**（品牌用越久越有價值） |

### 営業秘密：不申請，靠藏好

由**不正競争防止法**保護，三要件**全部符合**才算：

| 要件 | 意思 | 客戶名單的例子 |
|---|---|---|
| **秘密管理性** | 公司有在當秘密管理 | 標「社外秘」、設存取權限、上鎖 |
| **有用性** | 對事業有用 | 業務可拿來推銷 |
| **非公知性** | 外面查不到 | 不是網路上搜得到的資料 |

**最常考秘密管理性**：放在全公司都能存取、沒標示的共用資料夾的製程參數，再有價值，被離職員工帶走時也**不受保護**，因為缺秘密管理性。法律只保護「自己有在顧」的公司。

**保護期間：無期限**，只要沒外洩。

### 三種保護方式比較

| | 著作権 | 特許権 | 営業秘密 |
|---|---|---|---|
| 申請 | ❌ 創作時自動 | ✅ 特許庁 | ❌ |
| 公開 | 作品本身公開 | ✅ **必須公開** | ❌ **必須保密** |
| 期間 | 死後 70 年 | 申請起 20 年 | **無期限** |
| 保護對象 | 表現 | 發明（想法） | 管理好的秘密資訊 |

### 演算法要保護：特許 or 營業秘密

| | 特許権 | 営業秘密 |
|---|---|---|
| 優點 | **排他權**：別人就算自己獨立想出來也不能用 | 不公開、無期限 |
| 缺點 | 必須公開，20 年後大家都能用 | 別人**獨立開發**或**逆向分析**出來就擋不住 |
| 適合 | 藏在賣出去的產品裡、容易被拆解的技術 | 跑在自家伺服器、外面看不到的東西（如推薦演算法） |

例：知名飲料配方刻意不申請專利，當營業秘密藏了上百年。

## 前因後果

- **為什麼智財權要分這麼多種？** 因為要保護的東西性質不同：文化創作人人都能做，保護門檻低（不用申請）但只保護表現；產業發明影響大，國家用「給你獨佔 20 年，換你把內容公開」的交易來鼓勵技術進步；營業秘密則是公司選擇不做這筆交易，自己藏。
- **「公開換保護」vs「藏起來自保」** 是整節的主軸：特許是公開換排他權，營業秘密是靠保密但沒有排他權。
- **跟資安的接點在秘密管理性**：存取控制、資訊分類、標示（Ch3 資訊資產管理、Ch4 對策）不只是防外洩的技術手段，同時是**事後在法律上主張營業秘密的證據**。沒做好管理，被偷了也告不了。
- **著作權保護表現不保護想法**，跟特許權剛好互補：想法給特許，寫出來的程式給著作權。
- **跟 6-3 的接點**：職務著作屬於公司；外包時程式的著作權歸誰（請負→承包商、派遣→派遣先），6-3 會再接上。
