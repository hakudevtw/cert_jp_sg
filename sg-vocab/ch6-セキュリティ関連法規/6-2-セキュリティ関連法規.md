## ① サイバーセキュリティ基本法

2010 年代網路攻擊升級為國家等級的問題，但各部會各管各的、沒人統籌。2014 年訂這部法，先定下**誰負責什麼、由誰統籌**。

### 「基本法」的性質（常考陷阱）

| | 基本法 | 一般法律（例：不正アクセス禁止法） |
|---|---|---|
| 內容 | 理念、方向、各方責任 | 具體的禁止行為 |
| 罰則 | **❌ 沒有** | ✅ 有 |

罰則寫在**個別法**裡，但個別法不一定是根據基本法訂的（不正アクセス禁止法 1999 年就有，比基本法早）。基本法定方向、個別法定罰則，是分工關係。

### 法律規定的內容

1. **各方的責任（努力義務）**：國家、地方公共団体、重要社会基盤事業者（電力、瓦斯、金融、交通等重要基礎設施）、網路相關業者、大學、**連國民都有**。
2. **統籌機構**

| 機構 | 角色 |
|---|---|
| サイバーセキュリティ戦略本部 | 設在**內閣**，訂國家資安戰略 |
| 国家サイバー統括室（NCO） | 戰略本部的實務單位，**前身是 NISC**（2025 年改組）。舊題目看到 NISC 當作同一角色 |
| 国家安全保障局（NSS） | 國安政策的事務單位，事件牽涉國安時與 NCO 協作 |

3. **定義「サイバーセキュリティ」**：確保電子資訊的機密性・完整性・可用性（Ch3 的 CIA）。

## ② 刑法・不正アクセス禁止法：真的會罰人的法律

### 刑法的電腦相關罪

刑法原本為實體世界而寫，竄改銀行餘額這類行為「沒騙到人、沒偷到實物」，舊條文套不上，所以補了電腦版本：

| 罪名 | 對應的實體版 | 例子 |
|---|---|---|
| 電子計算機使用詐欺罪 | 詐欺 | 入侵銀行系統竄改自己的餘額 |
| 電子計算機損壊等業務妨害罪 | 妨害業務 | DoS 攻擊癱瘓公司網站、刪公司伺服器資料 |
| 電磁的記録不正作出及び供用罪 | 偽造文書 | 竄改系統裡的出勤紀錄 |
| 不正指令電磁的記録に関する罪 | （新類型） | 製作、提供、保管病毒 |
| 支払用カード電磁的記録に関する罪 | 偽造貨幣 | 側錄信用卡、做偽卡 |

**ウイルス作成罪最常考**：製作、提供、取得、保管就有罪，**不用真的感染別人**；但**有正當理由**的不算（防毒公司、研究員為分析保存樣本）。像持有槍枝：沒開槍也犯法，有執照的例外。

### 不正アクセス禁止法

專門管「未經授權登入別人的系統」。

| 行為 | 例子 |
|---|---|
| 不正アクセス行為 | 用別人帳密登入（なりすまし）、利用漏洞繞過登入 |
| 不正取得 | 為不正アクセス取得別人帳密 |
| 不正保管 | 為不正アクセス保存別人帳密 |
| **不正助長行為** | **把別人的帳密告訴第三者**（公開在論壇、賣掉），自己沒登入也有罪 |
| 不正入力要求 | 做フィッシング網站騙人輸入帳密 |

**適用前提（陷阱）**：
1. 透過**網路**存取。直接操作**沒連網的單機**不適用。
2. 系統有**存取控制機能**。本來就公開的頁面，看了不算。

系統管理者有做好存取控制的**努力義務**（無罰則）。

> 兩部法的共同邏輯：**在傷害發生之前就提早處罰**（病毒還沒散播、帳密還沒被用就違法），把防線往前推。跟 Ch4「讓前提不成立」是同一個想法。

## ③ 個人情報保護法

規範企業在**收集 → 使用 → 提供 → 外洩**每一步的規則。

### 四種個人情報

| 種類 | 定義 | 例子 |
|---|---|---|
| 個人情報 | **活著的人**的資訊，能識別是誰（含能輕易對照出是誰的） | 姓名＋生日、看得出是誰的照片或監視器影像 |
| 個人識別符号 | **單獨一個**就能識別 | 指紋、臉部特徵等**生物特徵**資料，護照、駕照號碼，マイナンバー |
| 要配慮個人情報 | 可能招致歧視、偏見 | 病歷、犯罪紀錄、人種、信仰、犯罪被害經歷 |
| 特定個人情報 | 含マイナンバー的個人情報 | 為報稅保存的員工マイナンバー（主要由マイナンバー法管） |

**陷阱**：死者的資訊、公司（法人）的資訊（公司名、營業額）都**不是**個人情報。

**要配慮個人情報：取得時就要本人同意。** 不是向委員會申請，委員會只在外洩時接受報告。

### 企業要守的規則

| 階段 | 規則 |
|---|---|
| 收集 | 利用目的要具體決定，並通知或公告 |
| 使用 | 只能在利用目的範圍內；超出要本人同意 |
| 提供給第三者 | 原則上要本人同意 |
| 保管 | 安全管理措施，並監督員工與外包商 |

例：以「出貨用」收集的地址拿去寄別家公司的廣告 → 超出利用目的。

### 匿名加工情報 vs 仮名加工情報

| | 匿名加工情報 | 仮名加工情報 |
|---|---|---|
| 加工程度 | 認不出是誰、**還原不回去** | 只換掉名字，對照其他資料**還能還原** |
| 提供第三者 | ✅ **不用本人同意**（要公告加工項目） | ❌ 只能公司內部分析 |
| 用途 | 大數據流通（例：交通卡移動紀錄去身分後給都市規劃研究） | 內部統計分析 |

### 外洩報告

主管機關：**個人情報保護委員会**。以下任一情況要**報告委員會並通知本人**：
1. 含要配慮個人情報
2. 可能造成財產損害（信用卡號等），**不論人數**
3. 不正目的（駭客攻擊、員工帶走）
4. 超過 1,000 人

**不用報告的兩個條件**：
| 條件 | 例子 |
|---|---|
| 做了高強度加密 | 筆電遺失但全碟加密、金鑰另外保管（即使超過 1,000 人也不用） |
| 被看到之前全部收回 | 寄錯信，對方還沒打開就確認刪除 |

> 共同點：**個人實際上沒有受害風險**。這也是 Ch2 加密的實際價值：外洩時能免於報告。

## ④ 特定電子メール法・其他法律

### 特定電子メール法

專門管**廣告垃圾郵件**。

| 方式 | 意思 | 日本現在 |
|---|---|---|
| **オプトイン** | **事先取得同意**才能寄 | ✅ 採用 |
| オプトアウト | 先寄，對方拒絕才停 | ❌（2008 年以前） |

> 記法：**in＝先「加入」（同意）才寄**；out＝預設就在裡面，要自己「退出」。

其他義務：寫明寄件者、取消訂閱方法；對方拒絕後不能再寄；保存同意紀錄。

| 適用 ✅ | 不適用 ❌ |
|---|---|
| **email 和 SMS 都算**（2008 年修法加入 SMS） | 非營利團體（NPO、政治團體）寄的 |
| 從**國外寄到日本國內**的也算 | |

> 「電子メール」不只字面上的 email。理由：只管 email 的話，業者換到簡訊就逃掉了。

不用事先同意的例外：交換過名片、已有交易關係、對方公開業務用信箱。

### 其他法律

| 法律 | 一句話 | 例子／考點 |
|---|---|---|
| マイナンバー法 | 管マイナンバー的使用 | 只能用在稅、社會保障、災害對策；當員工編號 ❌（有同意也不行） |
| 電子署名法 | 本人的電子署名與手寫簽名、蓋章同等效力 | 電子簽約推定為本人所簽 |
| 情報流通プラットフォーム対処法（**舊：プロバイダ責任制限法**） | 網路上權益受侵害時的平台處理規則 | 被誹謗可要求**刪除**、要求公開發文者身分（**発信者情報開示請求**）；平台適當處理則免責 |
| IT基本法 | 推動 IT 社會的基本法 | 2021 年由デジタル社会形成基本法取代 |
| **e-文書法** | **一般**法定保存的紙本文件**可以**掃描成電子檔保存 | 合約書掃描存檔 |
| **電子帳簿保存法** | **稅務**帳簿、收據的電子保存 | 電子交易資料**必須**電子保存 |
| 特定商取引法 | 管郵購、網購、上門推銷等易糾紛交易 | クーリングオフ、網購頁面要標示業者名稱與地址 |
| PL法（製造物責任法） | 產品缺陷造成損害，製造商**無過失也要賠** | **單獨的軟體不是製造物**（無形）；內建軟體的汽車、家電算 |
| GDPR | EU 的個人資料保護規則 | 見下方 |

> **e-文書法 vs 電子帳簿保存法**：看資料是不是**稅務**相關。一般文件 → e-文書法；稅務 → 電子帳簿保存法。

### GDPR

- **2018 年施行的 EU 規則**，保護 **EU 境內的人**的個人資料。
- **域外適用**：只要對 EU 境內的人**提供商品或服務**，或**追蹤他們的行為**（例如網站分析），**沒有 EU 分公司也要遵守**。例：日本網店接受法國客人下單。
- **資料移出 EU 有限制**：原則上只能移到 EU 認定保護水準足夠的國家（**十分性認定**）。日本 2019 年取得認定，所以 EU → 日本可以傳，但日本企業要遵守追加規則。
- **罰金很重**：最高 2,000 萬歐元或**全球營業額的 4%**（取較高者）。
- 代表性的權利：**被遺忘權**（忘れられる権利，要求刪除）、**資料可攜權**（把自己的資料帶到別家服務）。
- 外洩時原則上 **72 小時內**向監管機關報告。

## ⑤ 情報倫理

很多網路上的傷害不一定違法，靠個人判斷防範。

| 用語 | 內容 | 惡意 | 例子 |
|---|---|---|---|
| ミスインフォメーション | 假 | 無（誤會） | 長輩真心轉傳「喝熱水殺病毒」 |
| ディスインフォメーション | 假 | **有** | 選舉期間故意散播對手的假醜聞 |
| マルインフォメーション | **真** | 有 | 公開藝人真實的就醫紀錄、前任的私密照片 |

> 記法：mis＝錯、dis＝故意、mal＝惡意（malware 的 mal）。**陷阱：マルインフォメーション內容是真的**。
> 就醫紀錄＝要配慮個人情報，若是企業外洩也同時是 ③ 的問題。

- **デジタルタトゥー**：上網的東西被複製、截圖、轉傳後幾乎刪不掉。
- **ファクトチェック**：驗證資訊真假，日本有 JFC 等組織。個人做法：查來源、比對多個媒體再轉傳。大部分假消息是被「好心人」擴散的（misinformation）。

## 前因後果

- **法律的層次**：基本法定方向與責任（無罰則）→ 刑法、不正アクセス禁止法等個別法定罰則。考題常用「基本法有罰則」誘答。
- **「提早處罰」是網路犯罪法的主軸**：ウイルス作成罪（不用感染）、不正助長行為（不用登入）、不正取得與保管（還沒使用）。因為網路上的傷害一旦發生難以收拾。
- **個人情報保護法的設計是「目的綁定」**：先講好用途，就只能照用途用；要越界就回去問本人。匿名加工情報是為了讓資料能在「不傷害個人」的前提下流通。
- **加密的法律價值**：外洩時做了高強度加密就不用報告，把 Ch2 的技術跟法律義務接上。
- **跟 Ch1 的接點**：特定電子メール法對應スパムメール；不正入力要求對應フィッシング；業務妨害罪對應 DoS。
- **GDPR 的域外適用**反映網路沒有國界：保護的是「人」，而不是看公司設在哪裡。
