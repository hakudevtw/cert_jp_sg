## 本節的位置

5-6 講了 VLAN 怎麼在有線網路上切出邊界，也預告了無線 LAN 上的 VLAN 和 802.1X。本節把焦點放在無線本身：**有線要竊聽得接上那條線，無線的電波會飛出建築物**——所以無線 LAN 的所有安全機制都在回答「既然誰都收得到，怎麼讓只有該收的人讀得懂、連得上」。
① 為什麼無線特別危險 → ② 加密的兩個目的與 PSK → ③ 加密世代 → ④ 看似有效、其實不夠的對策 → ⑤ 頻出判斷原則：連線前 vs 連線後 → ⑥ 其他用語、威脅與對策總整理。

## ① 為什麼無線特別容易被竊聽

**無線 LAN＝不用 LAN ケーブル（實體網路線，屬第 1 層物理層 → 5-6）**就能連上內網。代表就是 **Wi-Fi**。比有線方便，**但更容易被竊聽**。

**不是協定比較弱，是「媒體」的性質不同：**

> **有線要竊聽，必須實際接上那條線；無線的電波會穿過牆壁，在停車場就收得到。**

| | 訊號送給誰 |
|---|---|
| **リピータハブ**（→ 5-6） | 往所有埠複製一份 → 全員收得到 |
| **無線 LAN** | **電波往四面八方發送 → 範圍內全員收得到** |

**無線 LAN 本質上就是「所有人共用同一條線」**，跟老式ハブ同一個結構。差別在**有線的ハブ至少要人進機房才碰得到，無線的「ハブ」範圍延伸到建築物外面。**

### 基本用語

| 用語 | 內容 |
|---|---|
| **親機（おやき）** | ＝**アクセスポイント（AP）**／**無線 LAN ルータ**。一邊用電波接子機，一邊用有線接內網 |
| **子機（こき）** | 透過無線 LAN 通信的機器：PC、手機、平板、遊戲機、印表機 |
| **SSID** | 連接親機時的識別名稱，**透過電波向周圍公開**。又稱 **ESSID** |

**SSID 與 ESSID**：嚴格說 SSID 指單一 AP 的網路名稱，ESSID 用於多台 AP 組成同一網路時。**考試上當同義詞處理。**

**「向周圍公開」的意思**：親機會**定期主動發送ビーコン信号（beacon）**廣播自己的 SSID——所以手機一開 Wi-Fi 就跳出一串名稱。

> **攻擊者什麼都不用做，光站在那裡就知道你有哪些無線網路。**

### 親機就是「邊界」

```mermaid
flowchart LR
    C1["子機<br/>PC・スマホ・プリンタ"] -.->|"電波<br/>（誰でも受信可能）"| AP["親機<br/>アクセスポイント"]
    AP -->|"有線 LAN"| INT["社内ネットワーク"]
```

子機那側是電波（誰都收得到），親機另一側是實體線直達內網。

> **只要有人成功連上無線 LAN，他就已經在你的內網裡了。**

## ② 加密的兩個目的：PSK 同時是入場券

| 目的 | 內容 |
|---|---|
| **通信被傍受（ぼうじゅ，攔截）也讀不懂** | 機密性 |
| **第三者無法輕易連上** | **存取控制** |

### ⚠️ 加密金鑰同時兼任「認證資訊」

> **不知道金鑰的人，根本連不上。**

家裡 Wi-Fi 那串密碼就是 **事前共有鍵（じぜんきょうゆうかぎ，PSK，Pre-Shared Key）／パスフレーズ（passphrase）**。**它既用來推導加密金鑰，也等於入場券。**

| 模式 | 內容 | 金鑰外洩時 |
|---|---|---|
| **パーソナルモード（WPA2-PSK）** | **全員共用一把 PSK** | **全公司要一起換** |
| **エンタープライズモード** | **IEEE 802.1X＋RADIUS**（→ 5-6）。每人有自己的帳號或クライアント証明書 | **停掉那一個帳號就好** |

**自編例**：離職員工手機裡存著公司 Wi-Fi 密碼。パーソナルモード下只能全公司換密碼、所有裝置重設；エンタープライズモード下停用他的帳號即可。

## ③ 加密技術的世代

| | 加密演算法 | 狀態 |
|---|---|---|
| **WEP**（Wired Equivalent Privacy） | **RC4** | **危殆化（きたいか）**（→ 2-1）。**幾分鐘內可破解，不可使用** |
| **WPA**（Wi-Fi Protected Access） | **TKIP** | 補強 WEP 的過渡方案 |
| **WPA2** | **AES**（CCMP） | **← 考題最愛問這個對應** |
| **WPA3** | **AES**（金鑰交換改用 **SAE**） | 最新，**但也已發現若干脆弱性** |

**由上到下，由弱到強。**

> **「WPA2＝AES」是必背的對應。**
> （修正：舊筆記把 WPA3 的演算法寫成 SAE。SAE 是 WPA3 新的金鑰交換／認證方式，用來取代 PSK 的握手；加密本身仍是 AES。考題若問 WPA3 的特徵，關鍵字是 SAE。）

### 「WPA3 也有脆弱性」本身就是考點

這正是 2-1 **危殆化**的本質：

> **沒有永遠安全的演算法，只有「目前還沒被攻破的」。密碼技術會過期。**

## ④ 看似有效、其實不夠的對策

② ③ 的加密是正面回答「誰都收得到」。下面兩個則試圖繞過這個前提，所以都失敗。

### SSID ステルス（SSID stealth）

**讓親機的電波不含 SSID 的功能。** 不開時親機會持續發訊號昭告存在；開了之後，知道 SSID 的人要**自己手動輸入**才能連。目的是防**不正アクセス（ふせいアクセス）**與**なりすまし**。

**⚠️ 但它比想像中弱很多（考點）：**

> **SSID 不只出現在ビーコン信号裡。**

子機連線時送**プローブ要求（probe request）**，親機回**プローブ応答（probe response）**，加入時還有**アソシエーション要求（association request）**——**這些訊框都帶著 SSID，而且是明文。**所以攻擊者只要在旁邊等，**等到任何一個正規使用者連線的瞬間，SSID 就暴露了。**

**而且有反效果：**

> **知道隱藏 SSID 的子機，會走到哪裡都主動大喊「請問 XXX 在不在？」**

因為對方不廣播，只能由子機主動探詢。**結果員工帶筆電去咖啡廳，那台筆電就在咖啡廳裡廣播公司的內部 SSID。**

> **結論：SSID ステルス只是「気休め（きやすめ，聊勝於無）」，不能取代加密。真正的防線永遠是 WPA2／WPA3。**

### MAC アドレスフィルタリング（MAC address filtering）

只讓登記過的網卡連線。看起來合理，但幾乎沒有防護力：

- **MAC アドレス可以偽造**
- **它在無線訊框裡是明文傳送的**

**攻擊者只要在旁邊監聽，就能抄到一個合法的 MAC，把自己改成那個。**

> **題目問「哪個對策不充分」時，MAC アドレスフィルタリング與 SSID ステルス是常見的正解。**

## ⑤ ⚠️ 頻出判斷原則：「阻止連線」還是「連線後的控制」

**典型設問（情境改寫，非原文）**：每次參加者都不同的公開研討會，要**阻止參加者以外的終端連上 AP**，哪個對策有效？

**四個候補裡只有一個在管「能不能連上」，其餘都是「連上之後」的事：**

| 功能 | 管的是什麼 | 對「阻止連線」有效嗎 |
|---|---|---|
| **DHCP（Dynamic Host Configuration Protocol）伺服器**的 IP 配發範圍 | 連上之後拿到什麼 IP | **✗** |
| **URL フィルタリング（URL filtering）** | 連上之後能看哪些網站 | **✗** |
| **每次更換事前共有鍵（PSK）** | **能不能連上** | **○ 正解** |
| **プライバシセパレータ（privacy separator）** | 連上之後能不能互相通信 | **✗** |

> **「不知道金鑰就連不上」——就是 ② 的「加密金鑰兼任認證資訊」的直接應用。**
> **每場換一次，是因為上一場的參加者也知道那把鑰匙。**

**解題時先問一句：這個功能作用在「連線之前」還是「連線之後」？**（同一原則 → 5-8 検疫ネットワーク。）

### 這題帶出的三個用語

| 用語 | 內容 |
|---|---|
| **DHCP サーバ** | 機器啟動時**自動配發 IP アドレス** |
| **URL フィルタリング** | 限制**能瀏覽哪些網站**，指定 URL 允許／拒絕 |
| **プライバシセパレータ**（＝アクセスポイントアイソレーション，AP isolation） | **禁止連在同一台 AP 的機器彼此直接通信** |

**プライバシセパレータ是公共 Wi-Fi 的標準配備**——咖啡廳裡的人連同一台 AP，**但彼此看不到對方的電腦**，防的是同一網路內的橫向偷窺。

**它與 5-6 的 VLAN 是同一個思想的微型版：都在切開「連在一起」與「能互相通信」這兩件事。**（使用者端自己關閉「網路探索」是同一個問題的另一面 → 4-3。）

## ⑥ 其他用語、威脅與對策總整理

### Wi-Fi Direct

**不經過アクセスポイント，裝置之間直接連線的技術**，其中一台臨時扮演 AP 的角色。
**典型場景**：手機直接印到印表機、兩台遊戲機對戰、畫面投影（Miracast）。**現場沒有任何 Wi-Fi 基地台也能用。**

> **⚠️ 容易誤解：「查出本機 IPv4，用手機輸入那個 IP 連進去」——那不是 Wi-Fi Direct。**
> 那仍然**透過路由器／AP 轉送**，只是沒繞到外網。**Wi-Fi Direct 連 AP 都不經過。**

### 威脅：ウォードライビング（war driving）

**開車／騎車帶著天線到處跑，尋找沒設防或加密很弱的無線網路。** 後果是**內部資訊被竊聽**，或伺服器・PC 的資訊**外洩、竄改、刪除**。

**延伸（愛考）：ウォーチョーキング（war chalking）**——找到之後**用粉筆在牆上或人行道畫記號**，告訴同夥這裡有可用的網路。名字來自 chalk（粉筆）。

### 對策總整理

| 對策 | 重點 |
|---|---|
| **使用可用的最強加密技術** | 盡可能 **WPA2 以上**，最低也要 WPA。**WEP 絕對不可用** |
| **パスフレーズ 20 字以上** | 破解靠**ブルートフォース（brute force，総当たり（そうあたり））**，**每多一字成本指數上升**。呼應 1-3「長度的效果大於複雜度」 |
| **收集接続ログ（せつぞくログ）** | **不防止任何事**，但沒有它就查不出誰在何時連過、做了什麼 |

**最後一項對應 5-2 的內部對策思想**：**承認有人會進來，所以要留下追蹤的能力**（→ 5-8 SIEM）。

## 前因後果

- **無線 LAN 是 Ch5 唯一一個「問題來自物理現實、而非設計選擇」的主題。** 前幾節的限制都是取捨的結果——防火牆放棄看內容是為了速度，IDS 只看副本是為了不擋住流量。**但電波會擴散是物理，不是誰選的。**

> **你無法讓電波只飛給該收的人。唯一的答案是「讓別人收得到但讀不懂」——也就是加密。**

- **所以加密是無線 LAN 唯一真正的防線**：SSID ステルス想「讓人不知道我在這裡」，MAC アドレスフィルタリング想「認出誰是自己人」——**兩者都試圖繞過「電波誰都收得到」這個前提，所以都失敗。只有加密是正面回答它的。**
- **所以加密技術一代一代換**：WEP → WPA → WPA2 → WPA3 就是 2-1 **危殆化**的實物展示，而且 WPA3 自己也有脆弱性——**「使用最新的加密技術」不是一次性的動作，是持續的義務。**
- **連線前 vs 連線後**：金鑰（PSK）管「能不能進」，其他功能管「進來之後」。這個區分接到 5-8 的検疫ネットワーク（連線前檢查），也呼應 5-2「侵入は防げない」——進來之後的事交給接続ログ與內部對策。
- **與其他節的連結**：

| 相關 | 連結 |
|---|---|
| **1-4 スニッフィング** | 無線 LAN 是竊聽門檻最低的環境 |
| **1-5 なりすまし** | 加密金鑰兼任認證，所以加密也是なりすまし對策 |
| **2-1 危殆化** | WEP→WPA3 是危殆化最清楚的實例 |
| **2-2 共通鍵暗号方式** | WPA2 的 AES |
| **5-6 リピータハブ** | **同一個結構：媒體被所有人共用** |
| **5-6 IEEE 802.1X** | エンタープライズモード就是它 |
