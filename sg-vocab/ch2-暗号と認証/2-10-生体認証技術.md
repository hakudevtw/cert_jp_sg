# 2-10 生体認証技術

重要度：★★☆

## 縮寫展開

| 縮寫 | 全名 | 日文 |
|---|---|---|
| **FRR** | **False Rejection Rate** | 本人拒否率 |
| **FAR** | **False Acceptance Rate** | 他人受入率 |
| **EER** | **Equal Error Rate** | 等誤り率 |

## 生体認証（バイオメトリクス認証）

透過人的**身體特徵**或**行動特徵**進行認證。屬於認証の三要素 中的 **Something you are**（→ 2-9）。

| | 身体的特徴 | 行動的特徴 |
|---|---|---|
| 比的是 | **長什麼樣** | **怎麼做** |
| 例 | 指紋、虹彩、網膜、静脈、顔、声紋 | **署名（筆跡）**、キーストローク、歩容 |

## 各方式の比較

| 方式 | 讀音 | 看什麼 | 特徵・弱點 |
|---|---|---|---|
| **静脈パターン認証** | じょうみゃく | 手掌或手指的**血管圖樣**（紅外線拍攝） | **體內資訊 → 極難偽造**，且**必須是活體**。ATM 廣泛採用 |
| **虹彩認証** | こうさい | 瞳孔周圍的紋路 | **一生幾乎不變**、**精度極高**、**非接觸** |
| **網膜認証** | もうまく | 眼底的血管圖樣 | 精度**極高**，但**必須把眼睛湊近裝置**，負擔大 → **不易普及** |
| **顔認証** | かお | 五官的位置與形狀 | **非接觸、自然**；受**化妝、老化、光線、雙胞胎**影響；**照片就能冒充** |
| **指紋認証** | しもん | 指尖的紋路 | **最普及、最便宜**；**手指乾燥、受傷、磨損**就讀不到；**指紋會殘留在物體上 → 可被複製** |
| **声紋認証** | せいもん | 聲音的頻率特徵 | **可透過電話進行**；**感冒、噪音**會影響；**錄音可重播冒充** |
| **署名認証** | しょめい | **筆圧・速度・運筆順序**（行動特徴） | **照著描一模一樣的字也過不了**，因為下筆節奏不同 |

### 特に問われる二つ

**① 静脈パターン 為什麼被視為最安全**
**它在身體內部。** 指紋、臉、虹彩都「露在外面」可被偷拍或採集；血管圖樣**接觸不到、看不見，而且死人驗不過**。

**② 署名認証 比的不是「簽出來的樣子」**
它同時測 **筆圧（ひつあつ）、速度、運筆順序**。
**這正是「行動的特徴」與「身体的特徴」的本質差異：前者比的是「怎麼做」，不是「長什麼樣」。**

### 生体検知（せいたいけんち，liveness detection）

確認眼前的是**活生生的人**，不是照片、錄音、矽膠指模。
**顔認証 與 声紋認証 特別需要它**（照片、錄音就能冒充）。

## メリット・デメリット

| | 內容 |
|---|---|
| **メリット** | **難以竊取、無法借出、不會遺忘、不用攜帶** |
| **デメリット①** | **機器建置成本高** |
| **デメリット②** | **変更できない**——外洩是**永久性的損害**（→ 2-9） |
| **デメリット③** | **受傷、老化、身體狀況**造成無法辨識 |
| **デメリット④** | **誤判**（見下） |

## 精度の指標：FRR・FAR・EER

| 指標 | 全名 | 意思 | 造成什麼 |
|---|---|---|---|
| **本人拒否率（FRR）** | False Rejection Rate | **把本人誤判為他人** | **不便**（本人進不去） |
| **他人受入率（FAR）** | False Acceptance Rate | **把他人誤判為本人** | **危險**（被冒用） |
| **等誤り率（EER）** | Equal Error Rate | FRR 與 FAR **兩條曲線的交叉點** | **EER 越低＝整體精度越好** |

### トレードオフ（必考）

> **判定閾值調嚴 → FAR 下降（安全），但 FRR 上升（本人也常被擋）**
> **判定閾值調鬆 → FRR 下降（方便），但 FAR 上升（容易被冒用）**
>
> **不存在「兩個都降到零」的設定。**

**所以生体認証 的調校，本質上是「安全性 vs 利便性」的取捨**——與 2-9 的 3D セキュア 2.0、リスクベース認証 是同一個命題。

**比較不同方式的性能時看 EER**，因為它把兩個指標整合成一個可比較的數字。

## 前因後果

**生体認証 是三要素中「最強也最脆弱」的一個，理解它的關鍵是分清楚這兩面。**

| 為什麼強 | 為什麼脆弱 |
|---|---|
| 無法借出、不會忘記、不用攜帶——**與「人」本身綁定** | **正因為與人綁定，所以壞掉了換不掉** |

密碼外洩改一個就好，IC カード 遺失補發就好，**但指紋外洩是終身的**。
**這是它無法單獨成為完整解答的根本原因**——所以實務上它幾乎總是作為**多要素認証的一環**，而不是唯一手段。

**與 Ch1・Ch2 的連結：**

| 相關節 | 連結 |
|---|---|
| 1-3 パスワードクラック | 生体認証 是「不使用密碼」的答案之一 |
| 1-5 なりすまし | 生体検知 正是對抗「用照片／錄音冒充」的技術 |
| 2-9 認証の三要素 | 本節是 Something you are 的展開 |
| 2-9 パスワードレス認証（FIDO） | FIDO 的認証器常以生体認証 解鎖——**但注意：生體資訊留在裝置內，不會送到伺服器** |

**最後一項值得特別記**：手機的指紋／臉部解鎖，**生體資訊從來沒有離開過你的手機**。
它只是用來「解開裝置裡的秘密鍵」，真正送到伺服器的是**公開鍵暗号方式的署名**（→ 2-3、2-9）。
**所以「生體資訊會被網站蒐集」是常見誤解**——在 FIDO 架構下並不會。

**這也回到 Ch2 的總結**：
**密碼學做的事不是「把秘密藏得更好」，而是「讓秘密根本不需要被送出去」。**
セッション鍵 用完即丟、チャレンジレスポンス 不傳密碼、FIDO 不傳生體資訊——**全都是同一個思想。**
