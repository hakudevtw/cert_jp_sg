# 常出現的日文詞（非專有名詞）

題目和テキスト裡反覆出現、但不是資安術語的一般日文詞。看不懂會整題誤解，所以單獨記。

| 日文 | 讀音 | 中文 | 備註 |
|---|---|---|---|
| 情報機器 | じょうほうきき | 資訊設備 | PC、伺服器、手機、印表機的總稱 |
| 可搬媒体 | かはんばいたい | 可攜式媒體 | USB、光碟等 |
| 記録媒体 | きろくばいたい | 儲存媒體 | — |
| 脆弱性 | ぜいじゃくせい | 弱點、漏洞 | vulnerability |
| 改ざん | かいざん | 竄改 | 常寫成假名「改ざん」 |
| 窃取 | せっしゅ | 竊取 | — |
| 詐取 | さしゅ | 詐取、騙取 | — |
| 漏えい | ろうえい | 外洩 | 常寫成「漏えい」 |
| 踏み台 | ふみだい | 跳板 | 被攻擊者當作攻擊他人的中繼站 |
| 遠隔操作 | えんかくそうさ | 遠端操控 | — |
| 不正 | ふせい | 不當、非法 | 不正アクセス、内部不正 |
| 持込み／持出し | もちこみ／もちだし | 帶入／帶出 | 資料或媒體的攜入攜出管理 |
| 標的 | ひょうてき | 目標、標靶 | 標的型攻撃 |
| 潜伏 | せんぷく | 潛伏 | — |
| 発病 | はつびょう | 發作 | — |
| 宿主 | しゅくしゅ | 宿主 | 病毒寄生的檔案 |
| 経路 | けいろ | 路徑 | 感染経路、攻撃経路 |
| 対策 | たいさく | 對策 | — |
| 措置 | そち | 措施、處置 | — |
| 運用 | うんよう | 營運、實際operation | 運用管理、運用ルール |
| 委託先 | いたくさき | 委外廠商 | 常考的責任歸屬對象 |
| 取引先 | とりひきさき | 往來廠商、客戶 | — |

| 恐れがある | おそれがある | 有…之虞 | 題目描述風險時的固定句型 |
| 講じる | こうじる | 採取（措施） | 「対策を講じる」 |
